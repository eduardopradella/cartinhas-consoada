# Cartinhas da Consoada — Landing page

Página estática (index.html + /images). Sem build.

## Antes de publicar anúncios
1. Em `index.html`, procure `var CHECKOUT` e cole os 2 links de checkout (Hotmart/Cakto): `essencial` (€9,90) e `completo` (€14,90).
2. Cole o código do Pixel Meta no `<head>` (comentário "PIXEL META").
3. Fotos em falta (enviar e guardar em `/images` com estes nomes exatos):
   - `foto-mesa-consoada.jpg` — mesa da Consoada posta, cadeira vazia, cestinha com cartinhas
   - `foto-maos-recortar.jpg` — mãos a recortar as cartinhas / cestinha com fita vermelha
   Enquanto não existirem, a página mostra um espaço reservado com a descrição.
